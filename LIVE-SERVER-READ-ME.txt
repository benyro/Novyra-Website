Cursor and VS Code only show the same site when both are editing **this same folder on disk**: the **`novyra-website`** directory inside your repo clone (not another path, not an old copy, and not the wrong workspace root).

**Do this in VS Code, in order:**

1. From the repo on your machine (for example on the Desktop), **double-click `OPEN-NOVYRA-IN-VSCODE.cmd`** in the repo root. That opens **`NOVYRA-WEBSITE.code-workspace`** so VS Code’s folder root is exactly what this project expects.

2. In VS Code, run **Developer: Reload Window** so extensions (especially Live Server) reload the workspace settings.

3. Open **`novyra-website/index.html`**, then **right-click in the editor → “Open with Live Server”** (or click **Go Live** in the status bar).

4. In the browser, use **`http://127.0.0.1:8766/`** only — that is the port set in this workspace. **Close any `:5500` tabs and remove old bookmarks**; that port is Live Server’s generic default and will not match this workspace.

Two URLs usually means two servers or two different folders. Trust **`http://127.0.0.1:8766/`** for this project after the steps above. If text or scripts still look old, hard-refresh (Ctrl+Shift+R) or bump the `?v=` query strings on JS/CSS in the HTML.
